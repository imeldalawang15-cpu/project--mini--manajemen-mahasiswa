# project--mini--manajemen-mahasiswa

## 📌 Fitur
1. Tambah Data di Awal
2. Tambah Data di Tengah (urut NIM)
3. Tambah Data di Akhir
4. Hapus Data Berdasarkan NIM
5. Cari Data Berdasarkan NIM
6. Tampilkan Semua Data

| Operasi | Kompleksitas |
|---|---|
| Tambah di Awal | O(1) |
| Tambah di Tengah/Akhir | O(n) |
| Cari NIM | O(n) |
| Hapus NIM | O(n) |
| Tampilkan Semua | O(n) |
